sdfmodeler ユーザーマニュアル

sdfmodeler は、階層的な SDF (符号付き距離場) モデルをブラウザ上でリアルタイムに モデリングするツールです。球・カプセル・楕円体などのプリミティブを smooth-union / smooth-subtract で滑らかに融合し、translate / rotate / mirror の 入れ子で関節階層を組み立てる、MagicaCSG 系のワークフローを再現します。 作ったモデルは sqm レンダラーの .ssq シーンとしてそのまま書き出せます。

1. 動作環境と起動

必要なもの: WebGL2 対応ブラウザ (Chrome / Safari / Firefox / Edge の最新版) と、 ローカル http サーバ (ES modules を使うため file:// では動きません)。

起動方法

# macOS
serve.command をダブルクリック   # 初回に警告が出たら右クリック→「開く」
./serve.sh                        # ターミナルから (または: python3 -m http.server 8642)

# Windows
serve.bat をダブルクリック        # (または: py -m http.server 8642)

# Linux
./serve.sh

ブラウザで http://localhost:8642 を開くと起動します。 Python 以外でも、任意の静的サーバ (npx serve など) で構いません。

作業内容はブラウザの localStorage に自動保存され、次回起動時に復元されます。

3. ビューポート操作

操作動作
ドラッグ注視点まわりの回転 (オービット)
Shift+ドラッグ / 右ドラッグパン (平行移動)
ホイールズーム
クリックパーツ選択 — クリックした表面を構成するプリミティブを ツリー上で選択。mirror で複製された側をクリックしても元ノードが選ばれます
矢印キー選択パーツの移動 — ←→は画面の左右 (カメラの向きに応じて X/Z 軸へ自動スナップ)、↑↓は上下 (Y軸)、Alt+↑↓は奥行き。 1回 0.1、Shift で 0.01 の微調整。グループ (演算/変換ノード) を選んで動かすと 自動的に「移動」ノードでラップされます。連続入力は1回の undo でまとめて戻せます

選択中のノード (とその配下) はオレンジ色にハイライトされます。 書き出し時のカメラは現在のビューがそのまま (camera ...) になります。

ギズモ (選択パーツの直接操作)

パーツを選択するとビューポートにギズモが出ます。ツールバーのプルダウン、 またはキー W=移動 / E=回転 / R=スケール でモードを切り替えます (いずれも Shift でスナップ)。

モード操作
移動 (W)XYZ 矢印=軸移動、色付き四角=平面移動、中央円=ビュー平面移動。 Shift=0.1 グリッドスナップ。グループを動かすと自動で「移動」ラップされます
回転 (E)3色リング=ワールド軸まわりの回転 (Shift=15°スナップ)。 リング中心の白ドットをドラッグすると pivot (回転中心=関節の曲がる位置) を移動。 rotate ノードが無いパーツでは deg=0 の回転が自動でラップされ、見た目を変えずに関節を仕込めます
スケール (R)軸ハンドル (四角チップ)=その方向の寸法、中央四角=一様拡縮 (Shift=×0.1 刻み)。対象はプリミティブ限定 — グループ選択時はサブツリー最初の スケール可能なプリミティブに委譲されます

掃引チューブ (sweep) の制御点: 移動モードで掃引チューブを選択すると、経路の各制御点に 緑ドットが表示されます。ドットをドラッグするとその点だけをビュー平面内で動かせます (Shift=0.1 スナップ)。奥行き方向に動かしたいときは視点を回してからドラッグしてください。 中央のギズモ本体はチューブ全体の平行移動です。スケールモードでは経路点が重心まわりに 拡縮されます (一様=半径も連動、軸=その成分のみ=形を潰す/伸ばす)。

4. シーンツリーとノード

シーンは複数のオブジェクト (surface = 材質 + SDF ツリー) からなり、 各オブジェクトの SDF ツリーは 3 種類のノードでできています:

種類 (ツリーの色)役割例
● プリミティブ (緑)形の素。距離場の葉ノード球, 楕円体, カプセル, 箱 …
⊕ CSG 演算 (青)子ノードたちを合成。子はいくつでも持てる和, 滑らか和(k), 差, 滑らか差(k), 積, 反転
↳ 変換 (黄)子ツリー全体を剛体変換。子は1つ移動, 回転, ミラー

関節階層の考え方: 「回転 → 移動 → 滑らか和 { カプセル, (次の関節…) }」を 入れ子にすると、腕や脚のようなリグになります。親の回転を変えるだけで 先端まで一緒に動きます。サンプルの frog の脚がこの構造です。

オブジェクト行の ◉ で表示/非表示、色スウォッチは surface の (color ...) を反映します。「＋ オブジェクト追加」で複数オブジェクトを併置できます (例: 水面 + キャラクター)。

5. インスペクタでの編集

数値の編集

数値フィールドは直接入力のほか、右端の 「↔」グリップを左右にドラッグすると スライダのように連続的に変えられます (Shift を押しながらで微調整)。 ドラッグ中もプレビューはリアルタイムに追従します (シェーダ再コンパイル不要)。

掃引チューブ (sweep) の点リスト編集

掃引チューブを選択すると、インスペクタに経路の制御点が「点N xyz r」の行で並びます (r = その点での半径。点ごとに変えるとテーパー=先細りになります)。

UI動作
x y z r の数値直接入力、または「↔」グリップの左右ドラッグ (再コンパイル不要で軽い)
◇その点と次の点との中間に新しい点を挿入 (半径も平均)。 粗く経路を引いてから細部を詰めるときに使います。ループ時は末尾→先頭の間にも挿入可
✕その点を削除 (2点までは減らせません)
＋ 点を追加終端の延長線上に外挿で追加
種類折れ線 / スプライン (Catmull-Rom=制御点を通る) / Bスプライン (近似=より締まる)
分割スプライン1スパンの分割数 (既定12)。上げると滑らか・レンダリングは重くなります
ループ端を結ぶ閉ループ (リング・結び目)
おすすめの流れ: カプセルを置く → 「⇄ タイプ変更 → 掃引チューブ」(2点の直線チューブになる) → ◇ で中間点を足す → ビューポートの緑ドットで形を彫る → r で先細り → スケールギズモで全体サイズ調整。ロープ/パイプ/蔓/取っ手/角 (つの) がこれ1本で作れます。

構造の編集

ボタン動作
⇄ タイプ変更選択ノードを別タイプに置き換え (球→カプセル、和→滑らか和 など)。 位置・サイズ・子ノードはできるだけ引き継がれます。プリミティブはプリミティブ同士で、 ラップ系 (CSG演算・変換) は種類をまたいで入れ替え可能 (移動→滑らか和、滑らか差→ミラー など。演算→変換は子が1つ以下のとき)。
※ 引き継ぎ先のないパラメータは失われます — 例えば「移動→滑らか和」では 移動量 t が消え、サブツリーは元の位置に戻ります。意図と違った場合は Ctrl/⌘+Z で入れ替え前に戻せます

オブジェクト / シーン設定

ツリーでオブジェクト名の行を選ぶと、名前・プレビュー色・surface (材質) の raw テキスト・背景色・ライトを編集できます。surface とライトは sqm の記法のまま 保持されるので、(shader ...) や (param ...) を含む高度な材質も 壊さずに読み書きできます。「オブジェクト複製」で SDF ツリーと材質ごと まるごと複製できます (複製直後は元と同じ位置に重なっているので、ルートノードを 選択して矢印キーで動かすと分離できます)。「オブジェクト削除」で削除。

6. チュートリアル: 簡単な生き物を作る

  1. 新規を押す。空のシーン (ルート=滑らか和 k=0.15) から始まり、 原点に軸クロス (X=赤, Y=緑, Z=青) が表示されます。
  2. ビューポート中央のクイック追加から球を選ぶ → 胴体になります。 以後パーツを足すたび、ルートの滑らか和で自動的にぬるっと融合します (融合の強さはルートノードの k をドラッグ)。
  3. ルートの滑らか和ノードを選択 →「＋ 子を追加」→ 楕円体。center を (0, 1.2, 0.3)、 radii を (0.5, 0.45, 0.5) 程度にドラッグ調整 → 頭ができます。
  4. 頭の楕円体を選択 →「＋ 兄弟を追加」→ カプセル。 a=(0.5, 0.6, 0), b=(0.9, 0, 0), radius=0.15 → 右腕。
  5. 腕のカプセルを「◇ ラップ」→ ミラー。normal は既定の (-1,0,0) のまま → 左腕が対称に生えます。以後、右側を編集すれば両側に反映。
  6. 腕を曲げたい時: カプセルを「◇ ラップ」→ 回転。pivot が付け根に自動設定されるので deg をドラッグ → 関節になります。
  7. 目のくぼみ: 頭の楕円体を「◇ ラップ」→ 滑らか差 → 子に小さい球を追加して 頭に少しめり込む位置へ。差の2番目以降の子が「削る側」です。
  8. ビューを好きな角度にして書き出し .ssq → sqm でレンダリング (次章)。
構造がわからなくなったら「サンプル: frog」を読み込み、ビューポートで各パーツを クリックしてツリーがどう組まれているか観察するのが早道です。

7. ファイルの読み書きと sqm でのレンダリング

.ssq 書き出し

「書き出し .ssq」で保存したファイルは、そのまま sqm でレンダリングできます:

./sqm -i model.ssq -o out.png -x 800 -y 600 -A 2 -s 2 -O 8 -T aces

カメラは書き出し時のビュー、背景・ライト・surface はエディタの設定が反映されます。 プレビューの見た目は簡易シェーディングですが、ジオメトリ (距離場) は sqm と同一の式で 評価しているため、形は本レンダと一致します。

ワンクリックテストレンダ (🎬 sqm ボタン)

ビューポート上部の 🎬 sqm ボタンで、モデリング中のシーンを現在のカメラのまま sqm で本レンダリングし、結果の PNG をその場に表示します (PNG保存も可)。 プレビューは単色近似なので、シェーダ・影・材質の実際の見た目を確認したいときに使います。

  • クリック = ドラフト (640px, AA1・ハード影, 数秒)
  • Shift+クリック = 高品質 (1000px, AA2・ソフト影・擬似GI, 数十秒〜)
serve.py 経由で開いていて、配信フォルダの隣に ../dist/sqm がある環境 (= sqm リポジトリ内) でのみ動きます。別の場所で使う場合は環境変数 SQM_BIN に sqm バイナリのパスを設定して serve.py を起動してください。zip 配布版を単体で開いた場合は エラーメッセージが出ます (モデリング機能には影響ありません)。

レンダリング設定タブ (⚙ レンダ設定)

ツールバーの ⚙ レンダ設定 で、別タブにレンダリングのパラメータ設定パネルが開きます。 解像度・アンチエイリアス・影・擬似GI・再帰深度・トーンマッピング・フレネル・被写界深度・ ブルーム・レンズ (色収差/周辺減光)・深度フォグなどを細かく設定し、「▶ レンダリング開始」 で sdfmodeler の現在シーンを本レンダリングして結果を表示します (PNG 保存可)。

  • プリセット: ドラフト / 標準 / 高品質 のワンクリック
  • 設定の保存: 変更は自動でブラウザに保存され、リロードしても復元されます。 「JSON 書き出し / 読み込み」で設定ファイルとして持ち出し・共有も可能
  • シーンは BroadcastChannel で sdfmodeler タブから取り寄せます (同じポートで開いておく)。 別ポート/未起動のときは「.ssq を読み込み」で直接指定できます
🎬 sqm ボタンが「今の構図でサッと確認」なのに対し、⚙ レンダ設定タブは 「品質・演出を作り込んで仕上げる」用途です。どちらも同じ ../dist/sqm を使います。

.ssq 読み込み

  • 既存の sqm シーンを開くと、各 object の SDF ツリーが編集可能な形で展開されます。
  • (rotate-mat ...) (MagicaCSG 等からの移植で使われる生の回転行列) は、 直交行列であれば自動的に編集しやすい (rotate (deg ...)) に復元されます。
  • エディタが対応しないプリミティブ (superquad, lathe など) は raw ノードとして テキストのまま保持されます。プレビューには出ませんが、書き出しで元通り出力されるため ラウンドトリップでシーンが壊れることはありません。
  • 入れ子の smooth-union チェーンは n-ary に平坦化して表示しますが、書き出し時に 元と同じ入れ子方向 (右fold / 差系は左fold) に戻すため、距離場は完全に一致します。

.json 保存

ノードにつけた名前や表示状態など、.ssq に載らない情報も保存する エディタ専用形式です。制作途中のプロジェクト保存にはこちらを使ってください。

9. 制限事項・トラブルシューティング

  • 手続きシェーダは単色プレビュー: ripples (波紋) や frog (斑点) などの sqm シェーダは、プレビューでは surface の (color) による単色近似です。 書き出しには完全な形で保持されます。
  • ノード名は .json のみ: .ssq フォーマットにノード名は存在しないため、 名前を残したい場合は .json でも保存してください。
  • raw ノード: 未対応プリミティブはプレビューに表示されません (書き出しは正常)。
  • 動作が重い: 品質を「高速」に、「影」をオフに。ノード数の多いモデルでは smooth-union の子を増やすほどレイマーチが重くなります。
  • 画面が真っ黒 / エラー表示: ステータスバーにシェーダエラーが出ます。 undo で直前の状態に戻ってください。
  • 「サンプル読込失敗」: file:// で開いています。http サーバ経由で 開き直してください (1章)。
  • 初期化したい: ブラウザの localStorage を消すか「新規」を押します。
  • プレビューとレンダ結果が違う: 3D プレビュー (WebGL) と 🎬/⚙ のレンダ (sqm 本体) は 別々の仕組みで描いています。ズレるときは大抵片方が古い状態です。①モデラーのタブを ハードリロード (⌘⇧R)、②レンダに使う sqm バイナリが最新か確認 (エンジンを 更新したら dist で make し直す。SQM_BIN で指すか、配信フォルダの 隣に最新の dist/sqm を置く)。同梱の起動スクリプトは既定でリポジトリの最新 sqm を使う設定です。
  • 「レンダ設定」タブや「断面を編集」が反応しない: 別タブ連携は同じポート (同じ URL) で開いたときだけ動きます。sdfmodeler と別タブが違うポートだと通信が届きません (適用時に警告が出ます)。
sdfmodeler — 階層SDFモデラー (sqm .ssq 対応)。検証: frog.ssq を import → export → sqm 本体でレンダリングし、オリジナルとピクセル一致を確認済み。
